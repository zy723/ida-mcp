# 20261022-1620 安装手册（手把手详细版）

## 问题

用户需要一份"手把手"级别的安装手册。仓库现有 README 是功能总览式文档，安装部分（手动安装一节）对新手缺少步骤级展开：没有 idalib 激活说明、没有部署物分布模型、没有排障表、没有升级/回滚/卸载流程。

## 根因

README 的受众假定为熟悉 uv/hcli 工具链的用户；`feat/port-ida-pro-mcp` 分支的 pro 工具面只能源码/wheel 安装（不在 PyPI），与官方一键安装的差异没有独立成篇讲清楚。

## 修改点

新增 `docs/INSTALL.zh-CN.md`（593 行），内容全部基于源码与本机实测编写，无臆造：

- 路线决策表（A 官方一键 / B 源码直跑 / C wheel 部署 / D 代理市场）；
- 前置条件检查表 + 代理网络配置（本机 Clash 7890 形态）；
- idalib 激活：`py-activate-idalib.py` 实际位于 `<IDA>\idalib\python\`（README.txt 写的是安装根目录，手册按实际位置写）；验证 `ida-config.json`；
- 部署三件套模型：①服务器 venv（含 ida-nexus console script 由 `ida_nexus/paths.py` 只查 sysconfig scripts 的事实）②GUI 插件（IDA 自带 Python）③客户端注册，一张表分清谁装在哪、被谁加载；
- 路线 B：`uv sync`、printf 冒烟、`claude mcp add` 完整命令；
- 路线 C：`uv build` → `uv venv` + `uv pip install --python` → 注册；
- GUI 插件：hcli 安装、撞名（ambiguous）处理（本机踩过：`ida-mcp-port`）、手动三件套复制；
- dbg 扩展开启（79→101 工具数）、CLI/环境变量速查、验收清单、升级/回滚/卸载、14 条 FAQ 排障表；
- 附录 A：官方一键安装；附录 B：关键事实源对照表（每条事实标注源码出处）。

## 影响范围
